# Weather Dashboard

A modern, responsive weather application built with React and Tailwind CSS. Get real-time weather information for any city worldwide with a beautiful, intuitive interface.

## 🌟 Features

- Real-time weather data from OpenWeather API
- Search weather information for any city
- Beautiful UI with smooth transitions
- Responsive design for all devices
- Dynamic background colors based on weather conditions
- Display of key weather metrics:
  - Temperature
  - Feels like temperature
  - Humidity
  - Wind speed
  - Weather conditions

## 🚀 Technologies Used

- React.js
- TypeScript
- Tailwind CSS
- Lucide React Icons
- OpenWeather API
- Vite

## 🛠️ Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/peterlee155/weather_app.git
   ```

2. Navigate to the project directory:
   ```bash
   cd weather_app
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Create a `.env` file in the root directory and add your OpenWeather API key:
   ```env
   VITE_API_KEY=your_api_key_here
   ```

5. Start the development server:
   ```bash
   npm run dev
   ```
